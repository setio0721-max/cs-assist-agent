온솜결 CS 답변 추천 (CSAssistant) - 사용법
==========================================

1. 실행
   - 압축을 푼 폴더에서 CSAssistant.exe 를 더블클릭합니다. 설치 과정은 없습니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다(서명 없는 프로그램이라 처음 한 번 뜰 수 있음).

2. 처음 한 번: API 키 설정 (둘 중 하나)
   (가) [설정] 화면에 키 입력 → [저장 후 연결]
        이 PC에만 저장됩니다(%APPDATA%\CSAssistant\config.json).
   (나) .env.example 을 복사해 이름을 .env 로 바꾸고 값을 채운 뒤 exe 옆에 둡니다.
        웹 앱 Streamlit Secrets 내용을 그대로 붙여넣어도 됩니다. .env 가 있으면 우선 사용합니다.

3. 사용
   - 고객 문의를 복사 → 입력 칸에 붙여넣기(또는 [클립보드 붙여넣기]) → [추천 받기] 또는 Ctrl+Enter
   - 답변 초안을 확인·수정 → [답변 복사] → 스마트스토어 답변 칸에 붙여넣기
   - 같은 고객의 이어지는 문의는 그대로 입력하면 앞 대화를 이어받습니다. 다른 고객은 [새 상담].
   - [항상 위]를 켜 두면 다른 창 위에 계속 보입니다.

4. 다른 노트북으로 옮기기
   - 폴더 전체를 USB·구글 드라이브로 복사하거나, GitHub Releases 에서 zip 을 다시 내려받습니다.
   - 키는 함께 옮겨지지 않습니다. 새 노트북에서 2번을 한 번 더 하거나 .env 파일만 따로 옮기세요.
   - 시연이 끝나면 시연 노트북의 .env 와 %APPDATA%\CSAssistant 폴더를 지우세요.

5. 안 될 때
   - "연결 실패": 인터넷 연결, Neo4j Aura·Qdrant Cloud 인스턴스가 일시정지(Paused) 상태인지 확인 후 Resume
   - "지식 0/3": Qdrant 에 CS 컬렉션이 없음 → Colab 적재 노트북 실행
   - 실행 자체가 막힘(기관 보안 정책): 웹 앱 https://cs-assist-agent-setio.streamlit.app 사용

※ 답변 초안은 반드시 검토 후 발송하세요. 생리대는 의약외품이므로 효능 표현 경고가 뜨면 문장을 확인하세요.
