# 고객 안내·배송 안내 — 온솜결 스토어 (수업용 가상 설정)

> 챗봇 지식 적재용 원천 문서(DOCUMENT_ID: policy)
> 출처: 스토어 고객 안내(취소·변경·교환·반품)·배송 안내 이미지 · 정리일 2026-11-26
> 실제 연락처는 반영하지 않음(전화번호는 가상 번호로 대체).

---

## 1. 주문 취소·변경

- 기본 원칙: **발송 준비 전까지** 취소·변경 가능.
- 주문 확인 전: 고객이 구매 내역에서 직접 취소·변경 가능.
- 주문 확인 후: 전화 및 문자 상담을 통해 **취소만** 요청 가능(변경 불가). 단, 출고 작업이 시작된 경우 요청이 거절될 수 있음.
- **예외 — N배송 상품: 주문 즉시 출고 작업이 진행되므로 수정·취소 불가.** N배송 관련 문의는 네이버 쇼핑&페이 고객센터로 안내.

## 2. 교환

- 택배사 사정으로 **원칙적으로 교환은 실시하지 않음.**
- 교환이 필요한 경우 **반품 후 재구매** 안내.

## 3. 반품 신청 조건

- **수령일로부터 7일 이내, 미개봉·미사용 상품**에 한해 가능.

## 4. 반품 불가

- 제품 특성상 **개봉하거나 사용한 제품**은 반품 불가.
- 사은품을 포함한 **구성품을 모두 보내야** 반품 처리 가능.
- **구매 확정 처리된 상품**은 원칙적으로 반품 불가.

## 5. 반품 배송비

| 사유 | 부담 |
|---|---|
| 주문 실수·단순 변심 | 고객 부담 |
| 상품 불량·오배송 | 판매자 혹은 택배사 부담 |
| N배송 반품 | 1회 무료 반품 가능 |

- 반품 배송비 금액: 안내문에 없음(확인 필요).

## 6. 배송 방식

| 항목 | N배송 | 일반배송 |
|---|---|---|
| 택배사 | CJ대한통운 | 한진택배 |
| 주문 마감 | 평일 낮 11시 | 평일 낮 12시 |
| 주말 출고 | 가능 | 불가 |
| 무료 배송 | 10,000원 이상(멤버십 회원 한정) | 35,000원 이상 |
| 주문 수정·취소 | 불가(주문 즉시 출고 작업) | 발송 준비 전까지 가능(1장 기준) |

- 주문 마감 시각 이후 주문은 다음 출고일에 출고되는 것으로 안내(마감 기준의 의미, 정확한 출고일은 주문 상태 확인 필요).
- 기본 배송비 금액(무료 기준 미만일 때): 안내문에 없음(확인 필요).

## 7. 주문 전 확인 사항

- **N배송 상품과 일반배송 상품은 함께 배송이 불가**하며, 배송비가 각각 부과됨.
- 도착 예정일은 **수도권 기준 평균**이며, 지역·기후에 따라 달라질 수 있음.

## 8. 고객센터

| 채널 | 용도 | 운영·답변 시간 |
|---|---|---|
| 전화 상담(가상 번호 000-0000-0000) | 긴급·특수 문의 | 오전 10:00~12:00, 오후 14:00~17:00, 주말·공휴일 휴무 |
| 문자 상담: 고객 문의·네이버 톡톡 | 일반 문의 | 답변 소요 1일 이내, 주말·공휴일 휴무 |
| 네이버 쇼핑&페이 고객센터 | N배송 관련 문의 | — |

## 9. 답변 작성 가이드(정책 문의)

| 문의 상황 | 답변 기준 |
|---|---|
| "주문 취소하고 싶어요" | **먼저 배송 방식 확인**: N배송이면 취소 불가 + 네이버 쇼핑&페이 고객센터 안내 / 일반배송이면 주문 확인 전 직접 취소, 확인 후 상담으로 취소 요청(출고 시작 시 거절 가능) |
| "사이즈를 잘못 샀어요, 교환돼요?" | 교환 미실시 → 미개봉·미사용이고 수령 7일 이내면 반품 후 재구매 안내, 단순 변심이므로 반품 배송비 고객 부담 |
| "한 개 뜯었는데 나머지 반품되나요?" | 개봉 제품은 반품 불가. 미개봉 묶음이 별도 포장 단위인지는 안내문에 없으므로 "확인 후 안내" |
| "불량이에요" | 판매자 혹은 택배사 부담으로 반품 처리, 사진 등 상태 확인 요청 |
| "언제 와요?" | 주문 마감 시각·주말 출고 여부 안내. 개별 주문의 배송 상태는 챗봇 범위 밖 → 구매 내역 확인 안내 |
| 금액이 안내문에 없는 질문(반품 배송비, 기본 배송비) | 추측하지 말고 "확인 후 안내" |
